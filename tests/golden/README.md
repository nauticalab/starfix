# Golden files

| File | Format | Status |
|---|---|---|
| `format2_v0.5.json` | hash format 2 (`000002…`) | **authoritative**; generated by `cargo run --bin emit_golden_format2`, append-only; checked by `tests/golden_vectors_format2.rs`; consumed unchanged by starfix-python |
| `format1_to_format2.json` | both | record of every format-1 golden or pinned value of this repository and its format-2 value |
| `include_metadata_v0.3.json` | hash format 1 (`000001…`) | **historical**, kept byte-identical; no longer asserted (format-1 hashes are computed by starfix 0.4); its inputs are re-hashed under the same ids in `format2_v0.5.json` |
